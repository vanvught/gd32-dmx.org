What this page shows

  • Device-specific RAM regions for supported MCUs
  • Section placement such as .stack, .heap, .data, .bss, .dmx, .pixel, and .network
  • Differences between families including GD32F2xx, GD32F4xx, GD32F47x, and GD32H75x

Why it matters

On embedded targets, memory placement directly affects performance, determinism, and feature capacity. Separating network, DMX, pixel, and core runtime data into appropriate memory regions makes the firmware easier to scale and tune across multiple MCU variants.

High-performance family

RAM GD32H75x

Architecture notes

The GD32H75x family provides multiple RAM regions, including tightly-coupled instruction and data memories as well as general-purpose RAM blocks. This allows workloads to be distributed according to latency and bandwidth needs.
