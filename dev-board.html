GD32F Development Board

A flexible development board for GD32F103Rx, GD32F303Rx, GD32F107Rx, GD32F207Rx, and GD32F407Rx devices. The board provides compatible headers, Ethernet-oriented variants, and practical pin access for firmware, networking, lighting, and general embedded development.

  • GD32F103Rx
  • GD32F303Rx
  • GD32F107Rx
  • GD32F207Rx
  • GD32F407Rx
  • Orange Pi / Raspberry Pi compatible headers
Board overview Pin headers

Overview

GitHub download. This board can be used with the GD32F103Rx, GD32F303Rx, GD32F107Rx, GD32F207Rx, and GD32F407Rx MCU families.

  • 25 MHz crystal for GD32F107Rx, GD32F207Rx, and GD32F407Rx
  • 8 MHz crystal for GD32F103Rx and GD32F303Rx
  • USB for power and DFU (Ethernet MCU only)
  • 2x13 header pin compatible with Orange Pi Zero and Raspberry Pi boards
  • 1x13 header pin compatible with Orange Pi Zero
